Model Adapter Scaffold Generator
================================

The ``generate_adapter_scaffold.py`` script under
``.agents/skills/areno-model-adaptation/scripts/`` reads a local HuggingFace
``config.json`` and generates an adapter directory structure with
registration code, checkpoint-mapping placeholders, and a minimal load
example.

Two scaffold types are supported:

* **dense**: Standard decoder-only transformer (attention + MLP per layer).
* **moe**: Mixture-of-experts transformer (attention + MoE per layer).

The generator never downloads assets or writes outside the requested
destination.  Reruns preserve user-edited files and report conflicts.

Usage
-----

.. code-block:: bash

   python .agents/skills/areno-model-adaptation/scripts/generate_adapter_scaffold.py \
       --hf-config /path/to/model/config.json \
       --adapter-name mymodel \
       --dest-dir areno/models/mymodel \
       --yes

Options
~~~~~~~

``--hf-config`` (required)
    Path to the HuggingFace ``config.json`` file.

``--adapter-name`` (required)
    Lowercase adapter identifier (e.g. ``mymodel``).

``--dest-dir`` (required)
    Destination directory for generated files.

``--yes``
    Accept all inferred choices without prompting.  Existing files are still
    preserved unless ``--overwrite`` is passed separately.

``--overwrite``
    Overwrite previously generated files that have been user-edited.

``--json``
    Emit machine-readable output containing both the inferred configuration
    and the created, preserved, and conflicted file lists.

Generated files
~~~~~~~~~~~~~~~

For a **dense** model:

* ``__init__.py`` — package init, re-exports the adapter class.
* ``model.py`` — decoder layer, causal LM, and ``ModelAdapter`` subclass.
* ``checkpoint.py`` — checkpoint load/save specs with TODO placeholders.
* ``example.py`` — minimal load example script.

For a **MoE** model:

* ``__init__.py`` — package init, re-exports the adapter class.
* ``model_moe.py`` — MoE decoder layer, causal LM, and adapter subclass.
* ``checkpoint.py`` — checkpoint specs with MoE TODO placeholders.
* ``example.py`` — minimal load example script.

Rerun safety
~~~~~~~~~~~~

The generator adds a ``# GENERATED BY`` sentinel to each file.  On rerun:

* **Unchanged generated files**: preserved (reported as "preserved").
* **User-edited generated files**: preserved (reported as "conflicted").
  Use ``--overwrite`` to replace them.
* **User-created files** (no sentinel): never overwritten.
* **Symbolic-link destinations or parents**: rejected before any files are
  created, so generation cannot escape through an existing linked directory.

Output
~~~~~~

The script prints:

* Inferred configuration (model type, architecture, dimensions, MoE status).
* Created/preserved/conflicted file lists.
* Next steps (fill in checkpoint specs, edit model code, register adapter).

Limitations
~~~~~~~~~~~

* The generated code is a starting point.  Checkpoint key mappings and
  architecture-specific details must be filled in manually.
* The generated package includes a ``register()`` helper.  Add a call to it in
  ``areno/models/__init__.py`` after reviewing the generated adapter.
* MoE scaffolds include a placeholder ``nn.Identity()`` for the MoE MLP that
  must be replaced with an actual implementation.
