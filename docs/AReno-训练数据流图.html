--tp-size / --world-size

world = dp×tp,决定并行切点;world=4 tp=4 → dp=1。

--algo

选 trainer + loss;gspo/grpo 走 rollout,sft/dpo 离线跳过阶段 2。

--reward-fn-path

阶段 3 的打分函数,纯 CPU 在 SDK 进程。

--agent-fn

Agentic 分支:本地 OpenAI 兼容端点 + 显式 trajectory,tool result 默认不计 loss。

--tune-params

正式跑前探测 KV 占用,回填 batch/running-prompts 保守值。

--attn-backend

attention 走 flash-attn 还是 areno 自研算子。
