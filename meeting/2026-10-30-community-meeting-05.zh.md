## 会议概要

AReno 第五次社区会议回顾了 0.10.0 版本的主要进展，包括 Mac/MLX QLoRA、CUDA 训练后直接导出 GGUF/Ollama、Qwen3.5 与多模态模型适配、JEV 决策模型训练，以及 Harbor 和 SWE-bench-style Agent 训练示例。团队同时讨论了推测解码、异构硬件、Agentic RL 和递归自我改进（Recursive Self-Improvement，RSI）的后续方向。

会议决定继续完善 JEV 和 RSI 能力，并在下周安排一次 RSI 专题讨论。近期社区工作将围绕技术大会、高校分享、内部推广案例和多平台内容发布展开。

## 会议议题

### 1. AReno 0.10.0 版本进展

本次版本主要完成了以下能力：

- 在 Apple Silicon 的 MLX 后端支持 QLoRA，并验证量化训练、适配器保存与重新加载流程。
- CUDA 训练完成后可直接导出 GGUF 和 Ollama 所需文件，无需额外转换工具。
- 补充 Qwen3.5、Bailing V3 MTP 和 Phi-4 Multimodal 等模型能力；多模态路径覆盖图像和音频等输入。
- 引入 JEV，支持在不同基础模型上训练模型无关的决策头，并覆盖 CUDA 与 Mac/MLX 路径。
- 集成 Harbor，打通 Agent、执行环境和训练流程，并提供 SWE-bench-style 软件工程任务示例。

### 2. 推测解码与模型能力规划

会议讨论了以 MTP 为基础的推测解码能力，以及后续跟进新型推测解码方法的必要性。团队将优先保证现有 MTP 路径稳定，再评估其他方法的训练成本、推理收益和适配复杂度。

JEV 将作为下一阶段重点能力继续完善。后续需要补充教程、示例和博客，说明决策头的训练、保存、加载和部署流程，并验证不同模型、量化方式和运行后端的兼容性。

### 3. Q4 技术路线

团队明确了第四季度的几个重点方向：

- 扩展异构硬件支持，继续推进与国产加速卡生态的合作，并完善 TPU 使用教程。
- 针对 Mac 和 DGX Spark 等个人开发者设备，继续优化显存占用、训练效率和模型覆盖。
- 加强 Agentic RL 能力，完善 Harbor 等执行环境与 AReno 训练链路的集成。
- 继续优化 GGUF/Ollama 等生态连接，让训练后的模型更容易进入本地推理和部署流程。
- 探索能够更新模型权重的 RSI 训练闭环，形成可复用的流程和评估方法。

### 4. RSI 场景讨论

会议重点比较了几个 RSI 概念验证场景：

- Kernel 编写 Agent：让 Agent 反复生成、测试和优化 GPU Kernel，以性能榜单或基准测试作为反馈。该场景评价信号清晰、资源需求相对可控。
- 数学任务：可通过生成题目、求解和训练构建闭环，但大规模采样成本较高。
- 具身智能：可关注 RoboDojo、RoboCasa 等仿真与评测环境，数据规模可能更小，但需要进一步确认训练是否会真正更新模型权重，而不仅是优化高层技能或提示词。

团队认为，当前许多 RSI 实践主要优化程序、技能或上下文，较少直接更新模型权重。AReno 的潜在差异化方向是把探索、数据生成、评估和权重训练串成完整闭环。下周将在 Kernel Agent 内部分享后安排一次专题会议，进一步选择首个场景并梳理通用框架需求。
