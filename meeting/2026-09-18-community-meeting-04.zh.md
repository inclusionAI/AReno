## 会议概要

AReno 第四次社区会议主要同步了硬件与多模态支持、AReno Flow、Mac 端训练能力和近期社区合作进展，并讨论了递归自我改进（Recursive Self-Improvement，RSI）方向的概念验证。

当前版本已基本完成华为昇腾 NPU 的初步适配，常见小模型可以正常运行；多模态支持进入收尾阶段。面向缺少本地 GPU 的用户，团队正在推进 AReno Flow，通过云端 GPU 和 Agent 交互降低训练门槛。会议决定在相关功能合入后于下周发布新版本，同时启动 AReno RSI 和 Mac 平台优化两个社区提案。

## 会议议题

### 1. 新版本与基础能力进展

会议同步了近期版本开发情况：

- 华为昇腾 NPU 的初步适配已基本完成，千问、百灵等常见小模型已完成或正在进行运行验证。
- 多模态相关能力进入收尾阶段，后续将在现有工作合入后规划下一阶段。
- 社区贡献的百灵 MTP 支持已经实现，仍需完成验证和合入。
- 新版本将等待昇腾 NPU、AReno Flow、MTP 等相关改动合入后，于下周统一发布。

### 2. AReno Flow

团队介绍了 AReno Flow 的初步方案。该能力面向没有本地 GPU，或只有低显存消费级显卡的用户，通过云端 GPU 提供更低门槛的训练环境。

主要设计包括：

- 用户提供云平台 API Token 后，即可通过 AReno 发起训练任务，无需自行准备 GPU 环境。
- AReno Desktop 中的 Agent 可以根据用户的模型和训练需求估算费用、推荐 GPU 型号并执行任务。
- 训练状态、指标和日志会回传到本地界面，便于用户跟踪任务。
- 后续可制作可复现的 demo，并与 Modal 等云平台社区开展内容和生态合作。

### 3. Mac 平台与本地小模型训练

会议讨论了 Mac Mini 和 Apple Silicon 设备在本地小模型训练、微调和推理中的价值。

主要观察和方向包括：

- 海外个人开发者较多使用 Mac Mini 进行小模型 serving 和 post-training。
- Apple Silicon 的统一内存架构为本地训练提供了相对易得的硬件环境。
- 当前已有基于 Mac Mini 的个人聊天记录微调 recipe 在迁移和验证中。
- 后续应进一步完善 AReno 在 Mac 上的稳定性、模型覆盖和显存优化能力。
- 可继续探索 4-bit Adam 等低比特优化器，降低本地训练的内存占用。

会议回顾了近期线下活动和后续合作机会：

- 下周将参加 Hermes 对外 Webinar，继续介绍 AReno 的相关实践。

### 5. AReno RSI 概念验证

会议讨论了将递归自我改进（RSI）引入 AReno 的探索方向。初步设想是让模型自主探索任务和能力边界，从失败或薄弱样例中生成训练数据，再通过训练形成迭代闭环。

初步流程包括：

1. 模型探索任务并识别失败样例或能力边界。
2. 模型自行生成或借助其他模型生成训练数据。
3. 使用生成的数据进行后训练。
4. 重复评估、生成数据和训练过程，形成持续迭代的闭环。

会议认为，RSI 的首个概念验证可以从优化 AReno 自身开始，重点是先搭建可复用的流程和技术能力，而不是预先限定最终效果。后续将形成简要 proposal，并在社区技术交流群中招募感兴趣的贡献者。

## 会议决策

- 新版本等待昇腾 NPU、AReno Flow、百灵 MTP 等改动完成验证和合入后，于下周发布。
- 继续完善 AReno Flow，并准备基于云端 GPU 的演示和社区合作内容。
- 启动 AReno RSI 概念验证，首个方向暂定为探索和优化 AReno 自身。
- 将 Mac 平台作为本地小模型训练和推理的重要方向，进一步完善支持和内存优化能力。
- AReno RSI 与 Mac 平台两个方向分别形成提案，并向社区公开招募贡献者。
- 推进 AReno 与高校课程的结合，并继续评估近期技术活动和大会分享机会。
