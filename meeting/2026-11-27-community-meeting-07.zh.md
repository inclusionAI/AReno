# AReno 社区会议 #7

日期：2026-11-27
录制时长：27 分 44 秒
形式：线上社区会议

## 会议概要

会议同步了 AReno 0.12.0 的发布准备，讨论了 Native Attention 的训推一致性、JEV 双向 Attention 和 OPD 算法支持。团队提出进一步完善 AReno Flow，用小模型在单机上驱动训练、诊断和部署，再结合递归自我改进（RSI）探索持续迭代。社区工作将继续围绕动手教程、高校交流和 Agent 主题分享展开，并评估 TTS 场景的单机训练合作。

## 会议议题

### 1. AReno 0.12.0 发布准备

- 计划于本周末发布 0.12.0，较上次会议的发布目标有所顺延。
- 默认训练与 rollout 路径转向优化后的 Native Attention，降低对 FlashAttention 的安装依赖。会上汇报，在已验证的训推一体配置下，rollout 与训练的 log-probability 差值可以达到零。
- JEV 相关训练增加双向 Attention 支持。会上汇报，相关实验的评测分数有十余分提升，具体评测口径和配置需在后续材料中补充。
- 开源之夏贡献的 OPD（On-Policy Distillation，在线策略蒸馏）算法已合入。
- 统一安装脚本仍需同步新后端方案，更新 FlashAttention 的安装逻辑。

### 2. AReno Flow 与小模型自我改进

团队讨论了 AReno Flow 的下一阶段方案，目标是由 Agent 完成任务启动、调参、故障诊断和服务部署，并把训练产出的 checkpoint 纳入后续迭代。

- 先在 DGX Spark 或 Mac mini 等单机环境中，用小模型驱动训练流程，验证端到端闭环。
- 探索让模型从训练任务执行过程中积累的数据学习，进一步改进其训练与诊断能力。
- 初步奖励信号可包括成功完成流程、发现并修复问题等，具体设计仍需细化。
- 结合启蒙正在推进的游戏 RSI 实验，讨论可复用的流程和能力。
- 该方案处于讨论阶段，需要另行细化首个任务、资源预算和效果指标。

### 3. 开发者教程与社区活动

- 面向更广泛的开发者，增加可以在本机完成、解决具体问题的教程和示例，从 Agent 使用场景逐步引入 RL。
- 继续准备香港科技大学的技术交流，内容聚焦单机扩展能力和训推一致性。
- 计划下周五赴南京金陵科技学院开展开源校园交流，安排学生现场运行 AReno。
- 讨论参与拟于 12 月 12 日在北京举办的 Agent 主题 Meetup，候选议题包括 RSI、Agent 训练和标准化实验流程，议题尚待确认。
- 继续筹备 12 月 18 日北京 AICon 分享，计划下周三试讲，并准备后续文章传播。
- 跟进开源之夏贡献者的持续参与，邀请相关同学参加社区会议。

### 4. TTS 与单机训练合作探索

- 屿涵分享了全双工语音模型、TTS（Text-to-Speech，语音合成）推理优化，以及多网卡流量调度相关工作。
- 双方讨论了在首版模型具备接入条件后，评估 AReno 对该场景的单机训练支持，并合作推进性能与显存优化。
- 屿涵计划在下周的内部交流中提出合作想法，再根据模型与训练需求确定后续安排。

## 会议决策

- 继续按本周末发布 0.12.0 的目标推进，并更新统一安装脚本。
- 细化 AReno Flow、小模型和 RSI 结合的概念验证方案。
